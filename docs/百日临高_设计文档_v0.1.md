# 《百日临高：执委会裁断》设计文档 v0.1

## 1. 项目定位

《百日临高：执委会裁断》是一款以《临高启明》同人语境为灵感的轻量卡牌决策游戏。

玩家扮演文德嗣，在登陆后的前 100 天中主持执委会日常裁断。游戏采用类似《王权》的左右划卡牌决策玩法：每张卡代表一个事件、请示、会议争议或外部压力，玩家必须在两个方向中选择其一，并维持各项压力的平衡。

第一版目标不是完整大战略，也不是还原全部原作剧情，而是做出“百日开局”的核心压力：内部要稳，外部要服，军务要控，生计要撑住，风声不能过早传开。

## 2. 核心体验

玩家不是皇帝，也不是全知上帝，而是执委会中的关键裁断者。

核心体验是：

> 每个选择都说得通，但没有一个选择是免费的。

玩家每天面对一张事件卡。左划通常偏向妥协、程序、安抚、缓行；右划通常偏向集中、强硬、加速、命令。但这不是绝对规则，具体含义由卡牌文本决定。

游戏追求的张力：

- 文德嗣有裁断权，但不能无视元老院。
- 临高需要生产和建设，但不能把民望压垮。
- 军务必须可靠，但军管化会带来反噬。
- 对外必须低调，但很多生存选择都会提高风声。

## 3. 玩家身份

玩家扮演执委会核心人物。


文德嗣的设计关键词：

- 执委会核心人物
- 强组织能力
- 强行政调度能力
- 有威望，但受元老院牵制
- 能在混乱中建立规则
- 需要协调、压服、交换和背锅

## 4. 明面四柱

第一版 UI 常驻显示四个指标。四柱不是普通资源库存，而是四种可能导致百日开局失败的压力来源。

### 4.1 元老院

代表内部政治支持、部门协同、派系容忍度，以及元老们是否仍愿意让文德嗣主持局面。

过低风险：

- 质疑
- 架空
- 部门拖延
- 会议否决
- 路线斗争

过高风险：

- 被元老利益绑架
- 部门分肥
- 会议政治膨胀
- 基层和民望被牺牲

### 4.2 民望

代表归化民、土著村社、工匠、劳力、周边百姓和地方社会对临高秩序的接受度。

过低风险：

- 抵制
- 逃亡
- 告密
- 村社冲突
- 外部合作断裂

过高风险：

- 让利过度
- 地方势力坐大
- 规矩变得可讨价还价
- 执委会认为文德嗣软弱

### 4.3 军务

代表保卫力量、纪律、治安、武装威慑和突发危机响应能力。

过低风险：

- 营地失控
- 偷盗
- 械斗
- 海盗、土豪或外部势力试探
- 命令无法落实

过高风险：

- 军管化
- 恐惧政治
- 元老院不安
- 民望下降
- 外部注意增加

### 4.4 生计

代表粮食、物资、住房、饮水、医疗、工程、工坊和基础生产能力的综合状态。

过低风险：

- 粮荒
- 缺药
- 工程停摆
- 营地生活崩溃
- 百日开局失败

过高风险：

- 生产至上
- 劳役过重
- 资源过度集中
- 民望和元老院承压
- 技术冒进事故

## 5. 隐藏压力

### 5.1 风声

风声代表官府警觉、士绅打听、海商传播、海盗注意和地方势力对临高异常的疑心。

风声不作为常驻 UI 指标显示，而是通过文本和阶段报告暗示：

- “此事恐怕会传出去。”
- “近来海商打听临高的人多了。”
- “县里似乎有人注意到了这边的动静。”

风声过高会触发外部危机卡，并可能导致“过早暴露”类结局。

设计原则：

- 风声低通常是好事。
- 风声不需要像四柱一样追求平衡。
- 风声越高，外部事件越危险。
- 玩家不应总能精确知道风声数值。

## 6. 时间规则

一局固定 100 天。

### 6.1 普通卡

普通卡推进 1 天。

这是游戏的默认节奏：每天一件必须裁断的事。

### 6.2 插入卡

插入卡推进 0 天。

用于表示同一天内的追问、会议反应、危机余波或连续裁断。

例子：

- 强制征粮后，村社代表当日求见。
- 否决扩大会议后，几名元老要求说明理由。
- 惩戒偷盗后，保卫组请求明确处罚尺度。

### 6.3 重大行动卡

重大行动卡推进 2 到 5 天。

用于表示需要持续投入的政策或工程。

例子：

- 集中修建临时码头：+4 天
- 全营卫生整顿：+3 天
- 民兵集中训练：+5 天
- 迁移临时营地：+3 天

重大行动卡的强度应高于普通卡，但会消耗宝贵时间。

### 6.4 阶段报告卡

阶段报告卡推进 0 天。

阶段报告用于切换阶段、总结局势、提示隐藏压力和预告下一阶段风险。

## 7. 阶段结构

百日分为四个阶段。

| 阶段 | 时间 | 主题 | 主要压力 |
| --- | ---: | --- | --- |
| 登陆阶段 | 第 1-15 天 | 卸载、安营、清点、第一接触 | 生计、军务 |
| 立足阶段 | 第 16-40 天 | 开荒、住房、卫生、规则 | 生计、民望 |
| 初期建设阶段 | 第 41-70 天 | 工坊、码头、制度、劳力 | 生计、元老院 |
| 稳定阶段 | 第 71-100 天 | 外部试探、路线成型、百日总结 | 四柱平衡、风声 |

### 7.1 登陆阶段

关键词：混乱、卸载、清点、安营、第一接触。

阶段目标：

> 把队伍和物资安顿下来，不在第一波混乱里失控。

常见事件：

- 船队卸载优先级
- 临时营地选址
- 失踪物资清点
- 第一批土著围观
- 元老要求召开扩大会议
- 保卫组要求设立警戒线

### 7.2 立足阶段

关键词：开荒、住房、卫生、组织、规则。

阶段目标：

> 让临时营地变成可以运转的据点。

常见事件：

- 是否雇佣本地劳力
- 开荒与修路争资源
- 疫病苗头
- 临时法规
- 工匠招募
- 村社纠纷
- 元老配给争议

### 7.3 初期建设阶段

关键词：工坊、码头、生产、制度、扩张。

阶段目标：

> 建立可持续生产能力，但不要把社会关系和内部政治压垮。

常见事件：

- 第一座工坊优先生产什么
- 码头是否加速
- 民兵训练方案
- 劳役制度争议
- 海商递话
- 明朝差役打听
- 技术保密问题
- 惩戒偷盗事件

### 7.4 稳定阶段

关键词：秩序成型、外部试探、路线定型、百日总结。

阶段目标：

> 熬过第一轮外部和内部审视，为长期临高政权打底。

常见事件：

- 官府来人问询
- 海盗试探
- 执委会百日质询
- 归化民安置
- 工坊事故
- 是否扩大招工
- 是否公开新规
- 百日路线报告

## 8. 卡牌系统 v0.1

### 8.1 卡牌字段

每张卡建议包含以下字段：

| 字段 | 说明 |
| --- | --- |
| id | 唯一卡牌 ID |
| title | 卡牌标题 |
| stage | 所属阶段，可为 all |
| type | 卡牌类型 |
| source | 来源人物、部门或势力 |
| text | 事件正文 |
| left_label | 左划选项短文本 |
| right_label | 右划选项短文本 |
| left_effects | 左划数值影响 |
| right_effects | 右划数值影响 |
| left_hint | 左划前给玩家看的倾向提示 |
| right_hint | 右划前给玩家看的倾向提示 |
| day_cost_left | 左划消耗天数 |
| day_cost_right | 右划消耗天数 |
| tags | 标签，如 survival、council、military |
| conditions | 出现条件 |
| followups | 可能插入的后续卡 |
| once | 是否一局只出现一次 |

### 8.2 卡牌类型

第一版卡牌分为六类。

#### 日常卡

最常见的普通裁断卡，默认推进 1 天。

#### 阶段关键卡

每个阶段必须出现的关键事件，用于保证一局有明确章节感。

#### 插入卡

由上一张卡触发，推进 0 天，表现同一天内的连锁反应。

#### 危机卡

当某个指标接近危险区时触发。危机卡应优先于普通日常卡。

#### 风声卡

由风声值或特定选择触发，表现外部世界开始注意临高。

#### 总结卡

阶段报告和百日结局使用，不计入普通抽卡池。

### 8.3 抽卡优先级

每天抽卡时，按以下优先级决定下一张卡：

1. 如果存在待处理插入卡，先出插入卡。
2. 如果当天到达阶段节点，出阶段报告卡。
3. 如果某指标进入危险区，优先出对应危机卡。
4. 如果风声达到阈值，可能出风声卡。
5. 如果当前阶段还有未出的阶段关键卡，按权重出阶段关键卡。
6. 否则从当前阶段普通卡池中按权重抽取日常卡。

### 8.4 指标范围

四个明面指标建议范围为 0-100。

初始值建议：

| 指标 | 初始值 |
| --- | ---: |
| 元老院 | 50 |
| 民望 | 50 |
| 军务 | 50 |
| 生计 | 50 |
| 风声 | 15 |

第一版可以直接采用固定初始值。后续可根据难度或主角路线调整。

### 8.5 危险区

建议将 20 以下和 80 以上视为危险区。

危险区不会立即失败，但会提高危机卡出现概率。

立即失败阈值：

- 四柱 <= 0
- 四柱 >= 100
- 风声 >= 100

后续可以改为 0 和 100 触发最终危机，而非立刻结束。

### 8.6 反馈方式

默认不显示精确数值变化，只显示方向和强度。

示例：

- 元老院 ↑
- 民望 ↓↓
- 军务 ↑↑
- 生计 ↓
- 风声似乎更紧了

可选设置：

- 精确数值模式：显示 +5、-8 等具体变化。
- 叙事模式：只显示自然语言提示。

## 9. 失败与结局

### 9.1 失败条件

四柱任一触底或爆满时触发失败结局。

风声过高时触发外部危机结局。

失败不一定意味着游戏世界毁灭，也可以是文德嗣被迫离开裁断位置、百日计划失败或临高进入不利路线。

### 9.2 百日结局方向

第 100 天后，根据四柱和风声给出路线评价。

候选结局：

- 稳健立足
- 铁腕百日
- 会议政治
- 民政优先
- 工坊路线
- 低调潜伏
- 过早暴露
- 执委会失衡

## 10. MVP 内容规模

第一版建议规模：

- 4 个显示指标
- 1 个隐藏风声
- 4 个阶段
- 50 张左右初始事件卡
- 12 张阶段关键卡
- 12 张危机/插入/风声卡
- 8 个结局
- 鼠标拖拽左右划
- 键盘 A/D 支持
- 阶段报告
- 简单存档

后续更新方向：

- 更多主角
- 元老派系
- 连锁事件
- 技术路线
- 地图节点
- 人物关系
- 特殊成就
- 历史压力曲线
