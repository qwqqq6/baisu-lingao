# 对白写作手册（卡牌内容规范 v2）

卡牌的呈现方式是**对话**：谁在对执政者说话、说了什么；选项就是执政者嘴里说出的批复台词。
本手册是写卡牌文案的规范。呈文公文腔（"伏乞批示""妥否"）只允许出现在**文书类事件**
（阶段报告、正式告示），其余一律对话体。

## 1. 基本格式

```json
{
  "id": "FARM-002",
  "text": "（保留一句场景白描，可选）",
  "lines": [
    { "who": "农庄管事", "line": "首长，秧等不得人。劳力还差一百二十个。" },
    { "who": "侦察排", "line": "俘虏营那边闲着也是闲着。" }
  ]
}
```

- `lines` 数组 1~4 条，一条一句话，别写成大段独白；
- `who` 是说话者的名衔（农庄管事、符家族老、保卫组组长），不写小说式心理描写；
- 选项 `label` 就是批复台词：**"没错，就这么办。""不行，再议。""先干着。"**
  —— 是人嘴里能说出来的话，不是"确立某某制度"这类文件标题。

## 2. 语域（谁说什么话）

| 说话人 | 语域 | 示例 |
| --- | --- | --- |
| 元老 | 现代口语带单位腔：排期、指标、扯皮、拍桌子 | 「这指标闭门造车，你让我怎么跟工地交代？」 |
| 归化民干部 | 半生不熟、态度恭顺但词不达意 | 「首长，工分的，明细不明白，请示下。」 |
| 本地士绅/族老 | 明代白话，客气里带分量 | 「爷，塘是祖宗塘，动了要遭雷谴的。」 |
| 保卫组 | 短句、下判断 | 「名单烧了，人心就散了。二选一。」 |
| 黎人/疍家 | 简短、直 | 「牛，换盐。换不换？」 |

## 3. 人物梗（专属卡复用）

- **文总**：背锅、和稀泥的茶局——「这本账，讨不得。」
- **督工（马千瞩）**：先看表再办事——「记上：三号棚灰浆，每日抽验。」
- **北炜**：嫌苛的去当第一具尸体；哨线是提前摆好的。
- **吴南海**：庄稼不哄人，它长给懂它的人看。
- **邬德**：先把人头数清楚；登记册比军令好使。

## 4. 红线

- **禁止文言腔**当对白（呈文套话仅限文书类事件）；
- **禁止粘贴小说原文**（已获授权的引用除外，需注明出处）；
- 选项台词必须每张卡单独写，禁止跨卡复用同一句；
- 一张卡的对话不超过 4 条，单条不超过 60 字为宜。
