# 文风指南（基于原著一至三卷 210 万字语料分析）

> 语料：临高启明公开图书馆（lgqm.halu.lu，论坛社区维护的原著阅读站）卷一「启航」~卷三「新社会」全文，2,097,314 字，612 节。
> 方法：称谓/词汇频率统计 + 逐类例句抽样。本指南是卡牌文案的**硬性规格**，与《重做规划》并列，改卡面文案前先读。
> 注意：游戏是「百日压缩」架空，芳草地/流通券/紫明楼等后期元素允许出现；但**说话方式必须按本指南分层**。

## 一、总纲：原文是什么味

1. **务实**。人物开口是为了谈成事：报价、数量、条件、去处。对白里全是实物名词和数字（"一百米的街道""一个月三十块冰票""库存不到 20 吨了"）。没有为气氛服务的对白。
2. **各说各话**。元老说现代话，土著说明代话，谁也不迁就谁。笑点恰恰产生在这种错位里（路大："回老爷的话，这不是粪，是氨水。"）。
3. **叙述夹私货**。作者/人物随时在句子里吐槽（"吴明晋只想抽他几个嘴巴""过去你怎么不这么卖力！吴明晋怨恨的想"）。卡面的 hint 和注脚可以带这种腹诽味。
4. **短句为主，话有半截**。口语允许省略、重复、改口（"过去我在苟老爷，不，苟大家当团丁的时候——他赶快纠正了自己的说法"）。
5. **具体压倒抽象**。写"髡贼们的计算方式"是配着"每星期去一趟东门市"落地的；不写"时间的流逝""历史的车轮"。

**易错点**：
- **"督工"全文仅 2 次（还都是动词）**。监工在原文叫"监工"（8 次）或直接点名。劳工线卡面不要用"X督工"当称呼；马千瞩下工地，土著叫他"马首长/马老爷"。
- "首长"是**归化系统内**的称呼；第一次接触的村民、外来客商一律"老爷"。写卡时先问：这人归化了吗？
- 元老**互相不叫首长**。值班秘书（归化民）呈文时叫"首长"正确；元老列传卡里元老开口叫彼此"文总/老邬/王工"。
- 原著卷一~三没有"伏波军""国民军""归化民"（皆 0 次）——早期是"教导营/特侦队/民兵""归化人/土著/职工"。游戏世界观压缩允许沿用后期名词，但**对白里土著嘴里不应主动出现这些词**，他们只会说"短毛的兵/澳洲人的营头"。

## 三、五层腔调与句式

### 1. 元老腔（元老互谈、会议、给玩家的人物卡对白）
- 现代口语直接平移，机构黑话自然混入：执委会（1167/万字 5.5，最高频机构词）、方案、预算、编制、体制、项目、汇报。
- 互相挖苦、抢话、拆台："别扯废话了！都到了大明还搞这套！"（独孤求婚）
- 谈正事极快进入细节："有多少预算？""船员，我们没有船员。"
- 口头语：得了（219）、什么/啥（155）、不成（170，反问句尾）、就是了（116）、嘿（98）、兔子（45，骂人货色）。
- 允许自我调侃和小算盘："我的目标是将来执委会给我一大块领地……当领主。"（王涛）

### 2. 归化民/职工腔（值班秘书、职员、士兵 → 首长）
- 汇报格式是**军操/公事腔**："报告首长！""报告！""请示下：见是不见？"（这句是原文原句，即游戏批牍体的原型）
- 敬语但内容实在，句式短："报告首长，巡逻队昨夜在文澜河抓住细作两名。""谢首长。"
- 带归化民特有的新词焦虑：说"氨水"时不知道自己在说什么（土著口中的新词一律直接念出来，不加解释性旁白）。
- 句尾"就是了/不成/来着"可用，但别过密。

### 3. 土著/村民/仆役腔（对老爷）
- 自称"小的"，回话起手"回老爷的话 / 回老爷"。
- 惧官、贪利、好奇三合一："小的知道不全，求老爷开恩！""能巴结上澳洲老爷，她爹喜欢都来不及。"
- 用明代概念框架理解新事物：冰块是"水火相交，冰火相攻，未免不合养生之道"；星期是"髡贼们的计算方式"。
- 民间叫穿越者"短毛"，兵叫"短毛的兵士"。

### 4. 官府/读书人腔（吴明晋、师爷、士绅、俘虏官佐）
- 心中"髡贼"，笔下口中看场合；公文里用"职/卑职/奉命/示下/札子"（频率都不高——原文官府戏靠**叙述+腹诽**而非公文套语，游戏批牍体保留但每卡至多一处套话）。
- 思维是资治通鉴式的："但凡造反作乱，一旦有读书人厕身其中，流毒祸害就会百倍千倍于几个泥腿子揭竿而起。"
- 对新事物的抵触总落在具体利害上：学田、膏火银、生员名额、俸禄外快。

### 5. 商贾/海盗腔
- 利益计算直白，黑话切口："他在级别上不过是刘香大帮里的一'股'，是个'掌柜'。"
- 夸货色、压价钱、赌咒发誓混着来："论到硝石火药，我这里的货色可比他的好得多。"

## 五、句式禁则（卡面逐条过）

1. 对白不超过两句一层意思；允许半截话、改口（"不，……"）。
2. 每段对白至少一个**实物**（米、盐、枪、船、银子、地契）或**数字**。
3. 叙事注脚可带腹诽（"过去你怎么不这么卖力！"式），但一卡至多一处。
4. 反问句是原文的重要武器（"有叫渔民老爷的么？""人凭什么给你卖命？"），好用但一卡至多一处。
5. 元老对白禁称"首长/领导们"互称；土著对白禁说"执委会/体制/项目"。
6. 卡面 title 用短语不用金句；选项 label 是首长批复指令（"照办。""缓办。""先押后。""叫他自己来。"）。
7. 结算反馈"照批"+四柱增减+至多两条注脚，注脚写成**旁人怎么看**（街谈巷议、衙门腹诽、商人算账），不写成作者总结陈词。

## 六、批牍体校准（本游戏特有体例的原文依据）

- 原型句：**"请示下：见是不见？"**（卷三）——呈文短笺到"请示下"即止，事项前置，问题直给。
- 呈文起手：呈 / 急呈 / 禀（衙门系统）。军警系统用"报告首长"。
- 首长批复：短促指令，可带情绪（"别扯废话了！"式驳回、"研究研究"式拖延——原文吴南海"当即表示研究研究"）。
- 一张卡的呈文 = 一件事：何人、何地、何物、要何批示。背景交代进 lines 或 hint，不堆进呈文。
