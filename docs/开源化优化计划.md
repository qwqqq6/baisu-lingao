# 开源化优化计划（v0.1）

> 目标：把《临高启明·执政者》从"本地可玩的同人原型"升级为**规范、可上手、可贡献、可持续**的开源项目。
> 本文档是路线图，随进展滚动更新；完成一项就在对应条目打勾。

---

## 1. 现状盘点

### 1.1 已有资产

| 资产 | 状态 |
| --- | --- |
| 可玩的游戏本体 | 原生 ES Module + JSON 内容包，无构建依赖；142 张卡、5 人物、8 系列、7 势力、52 状态 |
| 设计文档 | `docs/重做规划_v0.2`（权威规格）、`docs/状态管理类说明` |
| 内容校验 | `tools/validate_content.py`（结构/引用/命名空间检查，零错误基线） |
| 开发服务器 | `game/serve.py`（no-cache + 多线程） |
| AI 协作说明 | `AGENTS.md`（架构约定 + 文风约定 + 缓存纪元说明） |
| 中文用户文档 | `README.md`（运行方式 + 玩法要点 + 目录结构） |
| 美术资产 | 元老院旗（本地化 78KB）、纸墨风 CSS |

### 1.2 开源化差距（当前缺失）

- **法务**：无 LICENSE、无同人声明、无第三方素材出处记录
- **门面**：无截图/GIF、README 缺英文头、无 CONTRIBUTING / CODE_OF_CONDUCT / CHANGELOG
- **仓库卫生**：全部改动未提交；无 .gitignore（`.zcode/`、`__pycache__`、临时文件会被误提交）
- **质量保障**：无自动化测试、无 CI；内容校验只靠手动运行
- **工程化**：缓存版本 `?v=1` 靠手动递增；无代码规范工具；保存格式无版本迁移机制
- **可玩性缺口**（对照 v0.2 文档）：Mod 的 patch 操作、人物来信、势力收益深化、长事件链、结局影响继任
- **可及性**：无移动端适配打磨、无色弱对比度检查、无键盘操作
- **人物形象**：无头像立绘——选人页、对话、结局都缺"对面坐的是谁"的直观感
- **文体单一**：卡面为呈文批牍体，公文腔偏重，缺少"和活人对话"的临场感（增补对话体改造，见 §5.3）
- **模式单一**：无默认/调试双模式，想研究数值平衡只能翻代码

## 2. 目标定位与原则

**一句话定位**：一款以《临高启明》为背景的批牍体卡牌执政游戏——数据驱动、纯浏览器运行、社区可写内容包。

四条原则（后续所有取舍以此为准）：

1. **运行时零依赖**：浏览器原生 ES Module + JSON，玩家无需安装任何东西；Node/Python 只是开发工具。
2. **数据驱动**：人物、卡牌、势力、结局全部在内容包里；贡献者不写代码也能加内容。
3. **同人合规**：不碰原著版权红线（见 §3），代码与内容许可分离。
4. **小步可发布**：每个阶段结束都应有一个"外人能跑起来"的可用版本。

## 3. 版权与合规红线（最高优先级）

《临高启明》是吹牛者等人创作、连载于起点中文网的受版权保护作品。同人项目开源前必须把边界写清楚：

- [ ] **声明页**：README 与游戏内「关于」加入醒目声明——本项目为**非官方同人创作**，与原作者及起点中文网无关联；原著版权归原权利人所有。
- [x] **内容红线**：~~不得复制小说原文~~ **版权方已授权使用原文等信息（2026-09）**。引用原文仍须注明出自《临高启明》原作，禁止冒充原创；同人声明继续保留。
- [x] **双许可**：代码采用 `MIT License`（`LICENSE` 文件）；文案与美术内容采用 `CC BY-NC-SA 4.0`（`LICENSE-CONTENT` 文件），禁止商用——与同人性质一致。
- [x] **第三方素材台账**：`game/assets/CREDITS.md` 已建，元老院旗已登记（授权使用）。
- [ ] **Issue 模板**：加一条提醒，贡献内容时不得粘贴小说原文。

> ⚠️ 若未来收到权利人下架要求，应有预案：仓库转为"引擎+示例内容"模式，临高内容包独立分发。

## 5. 游玩体验优化计划（v0.2 增补）

> 本章回答一个问题：**玩起来什么感觉**。前三项（头像、双模式、对话体）是明确需求，第四项是补充建议。

### 5.1 人物头像系统

**目标**：选人页、对话卡、结局卡、纪事都能看到"这个人"。

| 方案 | 还原度 | 成本 | 版权风险 | 结论 |
| --- | --- | --- | --- | --- |
| A. 网络征集同人头像 | 最高（有原作神韵） | 中（逐张联系授权） | 中——必须获得作者明确授权并记入 CREDITS | 二期目标 |
| B. AI 生成统一画风 | 中上（统一风格，神韵靠提示词） | 低（一次出全套） | 低（声明 AI 生成即可） | **一期采用** |
| C. 内部统一美术（水墨/剪影/像素） | 中 | 高 | 无 | 兜底 |

- [ ] 一期：AI 生成五位首长半身像（统一画风与底色，突出辨识度：吴南海的草帽、邬德的登记册、北炜的钢枪、马千瞩的图纸、文德嗣的茶杯），512×512 PNG，命名=人物 id
- [ ] 二期：逐步替换为获得授权的同人图，`assets/CREDITS.md` 记录作者与许可
- [x] 渲染接入三处：选人页卡片、对话卡说话人头像、结局卡；缺图时以灰色剪影兜底
- **验收**：五人头像全部到位；无头像场景有兜底不破版

### 5.2 默认模式与调试模式

**目标**：默认模式保持"信息隐藏"的博弈设计；调试模式把引擎里已有的数据全部亮出来，服务平衡研究。

| 内容 | 默认模式 | 调试模式 |
| --- | --- | --- |
| 四柱 | 有数值条 | 数值条 + 精确数字（现有） |
| 风声 / 压力四项 / 合法性 | 完全隐藏 | 数值条 + 阈值标记（危险区高亮） |
| 势力面板 | 无 | 三列数值（影响力/满意度/敌意）+ 解锁状态 |
| 选项效果 | 仅极简批语 | hover 预览完整 deltas（四柱/风声/势力/压力分解） |
| 抽卡 | 不可见 | 当前系列权重表、候选卡列表 |
| 工具 | 无 | 跳天数、强制触发倒台/结局、随机种子显示与复现 |

- [x] 入口：标题页「调试模式」开关 + 游戏内右上角切换 + URL `?debug=1`；模式写入存档
- [x] 实现：**纯 UI 展示层开关**——数据本来都在内存，引擎零改动；效果预览复用 `describeChanges` 的映射
- **验收**：默认模式全屏截图无任何隐藏数值泄露；调试模式一屏看全上述六项

### 5.3 卡牌对话体改造（内容规范 v2，工作量最大）

**目标**：卡牌从"看公文"变成"和活人对话"——卡面显示**谁在对执政者说话、说了什么**（小说式白话，禁文言），选项就是**执政者嘴里说出的回复**。

- [x] **数据结构**：`text` 升级为 `lines: [{ who: "吴南海", line: "首长，秧等不得人啊……" }]`，支持 2~4 轮对话；渲染为带头像的对话气泡
- [x] **语言规范**（沉淀为《对白写作手册》，见 docs/对白写作手册.md）：
  - 全部白话口语，**禁止文言腔**（"伏乞批示""妥否"一类公文套话只保留在阶段报告等文书卡里）
  - 分角色语域：元老说现代口语带"单位腔"（排期、指标、扯皮）；本地士绅说明代白话（"爷""行个方便"）；归化民半生不熟（"首长，工分的，明细不明白"）；黎人疍家各有腔调
  - **执政者回复**：选项 label 就是台词——"没错，就这么办。""不行，再议。""先干，出了事我担着。"每张卡单独写，禁止套话复用
  - **人物梗**：专属卡复用名场面与口头禅——文总背锅账本、督工"先看表再办事"、北炜"嫌苛的去当第一具尸体"、吴南海"庄稼不哄人"
- [x] **改造流程**：10 张样板卡定规范后，全量 142 张已完成替换（每池 1 张 + 1 张人物卡）定规范 → 沉淀《对白写作手册》→ 全量 142 张替换 → 旧呈文体降级为专用（阶段报告、正式文书类事件保留）
- [x] 同步修订 `AGENTS.md` 文风总约定（批牍体 → 对话体，文书类除外）
- **验收**：随机抽 10 张卡盲测，能分清说话人身份与阵营；全库零文言腔；每张卡选项都是口语台词

### 5.4 补充体验建议（自提，按性价比排序）

1. **季节系统**：春夏秋冬轮转（每季约 10 回合），直接影响农事/台风/疫病卡权重——让台风、打摆子的出现"有天时依据"，低成本高沉浸
2. **音效**：批落实"落印"声、环境音（海浪/蝉鸣/集市叫卖）、静音开关
3. **新手引导**：前 5 张卡浮层提示——怎么看来源徽章、怎么理解隐藏信息设计
4. **史官记（时间线回放）**：结算页可回看每一次批复，形成"我这个执政者的一生"叙事
5. **结算统计页**：通关后解禁全程四柱/势力/压力曲线回看——弥补默认模式隐藏信息的后验爽感
6. **成就系统**：执政百日、五人全体验、八种结局达成、不靠伏波军通关……
7. **键盘操作**（1/2 选左右、空格继续）与**自动模式**（日常卡自动批复）
8. **难度三档**：轻松（压力衰减慢）/ 标准 / 苛刻（倒台阈值更低、官军来得更早）
